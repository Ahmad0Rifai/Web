# طريقة فتح المشروع وتسليمه

الاسم: Ahmad Alrifai — الرقم الجامعي: 2121032805.

## افتح الموقع على جهازك

1. فك ضغط ملف ZIP.
2. افتح مجلد `kampus-etkinlik` في VS Code عن طريق File → Open Folder.
3. افتح `sprint2/index.html` بالمتصفح لترى النسخة المنسقة.
4. افتح `sprint1/index.html` لترى نسخة HTML فقط.

لا تحتاج تنزيل CSS أو تثبيت Node.js. جميع الصور والخطوط البديلة محلية.
إذا لم يكن Palatino Linotype مثبتًا، سيستخدم المتصفح Palatino أو خط serif.
الملف المطلوب للدكتور هو `sprint2/css/2121032805.css`، وأوله اسمك ورقمك.

## الموجود في كل مرحلة

| الملف | وظيفته |
|---|---|
| index.html | الرئيسية وأقرب فعاليتين |
| etkinlikler.html | قائمة الفعاليات الثلاث |
| etkinlik-detay.html | تفاصيل الفعاليات والصور والموعد والمكان والسعة |
| etkinlik-ekle.html | نموذج إضافة فارغ مع حقول إلزامية |
| etkinlik-guncelle.html | نفس النموذج مع بيانات معبأة |

Sprint 1 بدون CSS أو JavaScript. Sprint 2 يحتوي CSS متجاوبًا ورقمك داخل
`--no`، ودرجة اللون 127، وخط Palatino Linotype لأن آخر رقم هو 7.
النماذج لا تحفظ بيانات؛ هذا مطلوب في هذه المرحلة. إرسال نموذج صحيح يعيد
فتح الصفحة، وإرسال نموذج ناقص يجب أن يمنعه المتصفح.

## فحص سريع عندك

1. افتح الصفحات الخمس وجرب القائمة وروابط تفاصيل الفعاليات.
2. اضغط Kaydet والنموذج فارغ؛ تأكد من تحذير المتصفح والحدود الحمراء.

بيئة التجهيز؛ لذلك هذه الخطوة مطلوبة عندك قبل التسليم.

## النشر

المشروع مجهز بتاريخ Git وعلامتي `sprint-01` و`sprint-02`.
لم يتم رفعه إلى حساب GitHub أو نشره على Vercel بعد.

تجد خطوات الرفع كاملة في `README.md`. عند إعداد Vercel استخدم:

- Framework: Other.
- Root Directory: sprint2 للنسخة النهائية.
- Build Command: فارغ.
- لا تحدد مجلد dist؛ المشروع HTML ثابت بدون build.

بعد النشر، أضف الرابط الحقيقي إلى README وافتحه على هاتفك. المطلوب للتسليم:
رابط GitHub، وعلامتا المرحلتين، ورابط Vercel. إذا كان الدكتور يريد عرض
Sprint 1 برابط منفصل، أنشئ له مشروع Vercel آخر بجذر sprint1، وأبقِ المشروع
النهائي بجذر sprint2.
